# Secrets

Secrets Manager examples:
- stackpulse/prod/stackpulse/database
- stackpulse/prod/stackpulse/application
- stackpulse/prod/second-app/database
- stackpulse/prod/second-app/application

SSM examples:
- /stackpulse/prod/stackpulse/API_URL
- /stackpulse/prod/stackpulse/ENVIRONMENT
- /stackpulse/prod/second-app/API_URL
- /stackpulse/prod/second-app/ENVIRONMENT

Never put passwords, JWT keys or database secrets into the AMI.
